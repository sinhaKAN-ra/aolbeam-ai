# **App Name**: Exam Prep AI

## Core Features:

- Problem Generation: Generate practice problems based on user-selected topics and problem types (theory or practical). The AI tool makes a distiction to customize a fitting problem.
- Problem Display: Display problems in a clear, interactive format suitable for either text-based answers (theory) or multiple-choice selection (practical).
- Answer Evaluation: Provide automated feedback on user-submitted answers for theory problems, assessing correctness and suggesting areas for improvement.  For multiple choice questions provide correct/incorrect feedback.
- Topic Details Retrieval: Fetch and display topic details from the internet to assist with revision, on user request.  This tool assists students who may want more review of key concepts.
- Navigation and History: Enable users to request similar problems, navigate to new topics, and review their problem-solving history (stored locally).

## Style Guidelines:

- Primary color: A calming blue (#64B5F6) to inspire confidence and focus.
- Background color: Light gray (#F0F4F7) for a distraction-free environment.
- Accent color: A bright orange (#FFB74D) to highlight key interactive elements, such as answer submission buttons or feedback notifications.
- Clean and readable font to ensure clarity and prevent eye strain during long study sessions.
- Simple, intuitive icons to represent different problem types and navigation options.
- The interface is divided into three sections: the first for viewing problems and interacting with practice problems, the second for additional topic revisions (retrieved via AI), and the third for the app's revision history
